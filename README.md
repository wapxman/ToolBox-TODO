# ToolBox-TODO

Внутренняя панель: канбан-доска задач (мини-Jira) + бухгалтерия.

## Возможности
- **Доска задач** — колонки-статусы (Бэклог → В работе → На проверке → Готово), drag-and-drop, приоритет, исполнитель, срок.
- **Бухгалтерия → Белая** — загрузка банковской выписки / выгрузки 1С (.xlsx/.csv), автоматический парсинг операций, статистика (приход/расход/баланс), графики, история импортов.
- **Бухгалтерия → Чёрная** — наличные вручную: записи Приход / Расход, баланс, статистика.

## Стек
Next.js 14 · TypeScript · Tailwind · Supabase · @dnd-kit · SheetJS (xlsx) · Recharts

## Запуск
```bash
npm install
cp .env.example .env.local   # заполнить ключи Supabase
npm run dev
```
